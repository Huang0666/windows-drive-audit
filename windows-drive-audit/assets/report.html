占用数字与清理建议怎么读

含子目录占用显示当前目录和下层文件的合计。往下打开目录就会看到其中的明细。要相加时使用「仅本层」列。NTFS 硬链接对应同一份文件时，实际占用只分配给首次扫描到的路径。

目录名线索是按名称推断。一个目录同时含程序、设置、个人文件和缓存时，请查看下层目录。读取有缺项时，表中仅显示可见部分。链接与挂载点列出本身，目标可能位于另一个盘。盘级差额也可能包含 NTFS 维护数据。

「可重建或旧残留」的具体条件在每行。系统文件可从 Windows 设置的「系统 → 存储 → 临时文件」核对，应用程序使用各自的卸载入口。
